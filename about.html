ABOUT THE PROJECT

Simple design.
Better listening.

Listen. is a frontend music player website created using HTML and CSS. The project focuses on creating a clean, modern and easy-to-use music interface.

01

HTML

HTML is used to create the structure of the website, including pages, navigation, song information and audio players.

02

CSS

CSS is used to design the website, control layouts, colours, spacing, buttons, cards and responsive behaviour.

03

Audio

HTML5 audio controls allow users to play the music files directly from the website without JavaScript.

PROJECT CONCEPT

A clean music experience built with basic web technologies.

The project demonstrates the use of multiple HTML pages, external CSS, navigation links, responsive layouts and HTML5 audio elements.
