# Listen. - Music Player Website

A beginner-friendly music website made with HTML, CSS and JavaScript.

## Pages
- Home
- Library (includes song search)
- About
- Contact (feedback form)
- Request a Song
- Login (front-end demo only)

## Run the project
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal in that folder.
4. Run `node server.js`.
5. Open http://localhost:3000 in your browser.

The Contact and Request a Song forms send data to the local server. Submissions are saved in `data/submissions.json`.

Note: GitHub Pages can host the static website, but it cannot run this Node.js server. Run the project locally with Node.js to demonstrate JSON form saving.
